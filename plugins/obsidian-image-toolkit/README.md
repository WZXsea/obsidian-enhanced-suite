# Image Toolkit 台前图片导航扩展

## 框选复制与预览动画（1.4.18）

1. 桌面预览底部工具栏最右侧新增“框选复制”（四角框图标）。点击后在图片上拖动矩形，松开鼠标即可将选区复制为 PNG。拖动时显示导出宽高，按 Esc 可退出框选并保留预览。
2. 选区映射到原图的整数像素，按原始分辨率导出，并保留当前旋转和镜像方向。缩放比例与屏幕像素密度独立于导出尺寸。颜色沿用原图，透明像素保留。
3. 图床图片通过 Obsidian 请求接口读取原始字节后裁剪，本地图片直接解码。框选期间点击缩放、旋转、刷新或画廊条目会结束本次选区；等待复制时关闭预览或切换图片会取消尚待写入的剪贴板任务。
4. 点击正文、导航或图库图片打开桌面预览时，以约 280 ms 从原图位置放大，背景与工具栏同时淡入。系统开启“减少动态效果”时即时显示，开始拖动或缩放时立即交还图片控制权。

核验：47 项自动测试、TypeScript 构建通过。真实 macOS Obsidian 的 50% 和 25% 缩放均导出 800 × 400 px；90°旋转并镜像后导出 400 × 800 px；图床图片同样按原像素复制。三种显示状态及图床图片的 PNG 解码结果与原图选区逐像素一致。实际界面还覆盖 Esc、工具栏模式切换、方向键状态清理及预览动画。记录见 `output/crop-motion/results.json`，界面复核脚本为 `qa-crop-motion.py`。

## 移动导航交互修正（1.4.17）

1. 手机和平板的图片导航保持展开状态，侧栏内滚动、手指离开、窗口尺寸变化与焦点变化均保留导航。点按“×”或在正文完成一次外部轻触可收起导航。
2. 移动端单击缩略图定位正文中的对应图片，条目旁的“↗”打开大图。定位沿用当前阅读或编辑模式。阅读模式先以源码行挂载对应区段，再以精确图片引用位置对齐，同图多次引用保持各自位置。
3. 与图片布局插件联动时，导航可以直接显示图库内部的指定图片。页面工具栏与页面菜单提供“图片”入口。


## Android 适配（1.4.16）

1. Android 使用 Obsidian 原生 Modal 图片查看器。点按正文图片、导航缩略图或画廊放大按钮均可打开。工具栏提供上一张、下一张、放大、缩小、适应窗口、旋转和关闭。
2. 查看器支持单指平移与双指缩放。手指离开、系统取消触摸或关闭弹窗时清理本次手势。桌面沿用原有 Image Toolkit 查看器。
3. Android 图片导航以可点按的左缘入口展开，点按外部收起。功能区按钮或“打开文章图片台前导航”命令同样可以展开。导航列表保留纵向滚动。
4. 图片布局桥接继续按画廊源码顺序传递图片，重复图片保留各自索引。插件清单开放移动端加载，构建后的运行时代码通过浏览器 Web Crypto 生成窗口标识。
5. 适配验证覆盖构建、模型回归、触摸生命周期和仅提供 Obsidian 模块的 bundle 加载。Android 真机的 WebView、系统返回键、软键盘和具体主题组合仍需设备验收。


基于本机 Image Toolkit 1.4.3 的本地定制升级，当前版本 1.4.15。保留原图片放大、旋转、拖动和底部画廊，新增文章左侧无外框的悬浮图片导航与正文图片组联动。

## 使用

在 Obsidian 设置 → Image Toolkit → 图片导航设置中选择“台前调度式图片导航”：

- 始终显示：显示纵向缩略图卡片，移入或聚焦单张图片时，该图片转正并放大，导航宽度保持稳定。
- 悬停显示：文章左侧纵向边缘为透明触发区域，移入时图片集合用 300ms 淡入；移出保留 180ms 缓冲再用 300ms 淡出，导航宽度保持稳定。
- 关闭：收起导航；可用设置中的“显示导航”、应用左侧功能区图标或命令重新开启。

缩略图支持上下滚动、点击放大，以及右键菜单“跳转到图片位置”。图片保持正文顺序，重复出现保留各自定位。支持 Markdown、Wiki 图片嵌入、引用图片与 HTML img；本地图片使用 Obsidian 的链接解析和资源 URI，图床图片沿用原 URL。

## 开发

```sh
npm install
npm run build
npm test
```

`src/main.ts` 管理悬浮导航、文档更新与正文定位，`src/images.ts` 解析图片引用，`sidebar.css` 提供悬浮卡片样式。`upstream/` 保存升级前的运行文件。构建脚本以明确锚点插入图片导航设置与图片集合适配，继承原插件并通过 Component 子组件管理扩展生命周期。锚点变化会中止构建，便于升级原插件时重新审查。

构建产物为 `main.js`、`styles.css`、`manifest.json`，复制到库的 `.obsidian/plugins/obsidian-image-toolkit/` 后重新加载。原设置文件 data.json 由 Image Toolkit 管理，新选项为 `noteImageStageMode` 与 `noteImageStageWidth`。默认宽度 180px，可拖动右缘或通过设置滑块调整为 120–320px；调整结果自动保存。

## 1.4.7 收回状态修复

悬停模式由显式显示状态控制。点击触发区域仅打开导航，点击正文或导航空白处、鼠标移出、窗口失焦、窗口及文档面板尺寸改变、Esc 均会收回，并清理内部焦点。文档捕获监听、窗口监听、ResizeObserver 与移出计时器在重建及卸载时统一释放。

在当前 Obsidian 中定向派发事件核验：正文点击、空白处点击、移出、resize、blur、Esc 后 revealed、expanded 与 focus 均为 false；图片内部 pointerdown 后 revealed 保持 true。

## 1.4.8 触发边界

透明触发区由 28px 收紧为文章面板最左缘 6px，悬停停留 120ms 后触发；提前离开会取消触发。移动到标题折叠按钮或编辑器折叠栏时清理显示及待触发状态。当前界面核验触发区与可见标题折叠箭头的几何范围分离；短暂穿过边缘、停留触发及折叠箭头移入收回均通过定向检查。

## 1.4.9 阅读位置跟随

正文滚动后以视口上部阅读锚点对应的源行选择最近已读到的图片，自动滚动缩略图列表并用图注颜色及小圆点标记当前图片。编辑视图通过 CM6 坐标映射，阅读视图通过渲染 section 的源行及几何位置映射；读取接口提供能力检测与后备路径。正文位置保持原样，仅滚动缩略图列表。手动滚动或操作图片导航后暂停自动跟随 2.5 秒，再恢复。

14 项单元测试通过。当前文章编辑及阅读视图中，从第 115 行图片切换到第 576 行图片，当前图片标记同步更新，导航 scrollTop 从 0 更新到 1796。手动 wheel 后标记保持在第 292 行，缓冲期结束恢复到正文所在的第 115 行图片。

## 1.4.10 当前图片光晕

阅读位置对应的缩略图增加沿图片圆角轮廓的主题强调色光晕，随当前图片标记移动。光晕采用细轮廓与两层柔和外光，保持其它图片的轻阴影，以及原有的倾斜、转近与导航淡入淡出动效。

## 1.4.11 可见图片判定与光圈

优先从当前模式的正文容器扫描实际可见图片，按视口中心的覆盖及距离选取当前图，小图按位置参与选择，过滤仅擦边出现的图片；当前正文无图时回退到源行判定。CM6 posAtDOM 或阅读渲染器 section 源行用于匹配重复图片的具体出现位置。手动浏览导航只暂停缩略图自动滚动，当前图片标记继续更新。图片加载后重新判定，正文滚动以 80ms 间隔合并更新。

光圈增强为 3px 实色轮廓与 14px/28px 双层外光。20 项单元测试通过；截图场景的第9图 image.png（源行328）在编辑与阅读视图均正确选中，原第8图（源行291）已位于视口上方。

## 1.4.12 当前图片居中与首尾占位

自动跟随时将当前图片本身的中心对齐缩略图视口中线。顶部及底部各加入半个缩略图视口高度的留白占位，保留足够滚动空间，首张及末张也可以居中；留白采用淡化点阵和“从这里，读见更多”“读到这里，渐见全貌”文案。占位在图片载入、尺寸及视口变化时同步更新，手动浏览缓冲继续保留。

当前界面实测：一般图片居中误差 0.194px，首张 0.159px；末张所需 scrollTop=2390.37、小于可用上限2500，居中误差 -0.126px。正文阅读位置保持独立，仅图片栏自动滚动。

## 1.4.15 侧边悬停恢复
导航按可见Markdown面板独立维护。切换文章、模式与窗口时立即协调，正文内容变化保留原有合并调度；失联的旧导航实例自动重建，后台窗口保留主文章的导航与当前活动位置。悬停和收回计时器、尺寸观察与焦点判断使用所属窗口。

侧栏放大和右键定位捕获所属笔记，重复图片保留独立索引；放大优先使用正文图片组桥接。尺寸观察回调通过动画帧或已有80 ms调度更新，仅实际高度变化时写入书挡尺寸。

无图笔记复用已完成的空状态；有图节点脱离页面时重新挂载。类名和占位高度在实际变化时写入，保持视图观察稳定。

严格TypeScript构建和29项自动回归测试通过。实际Obsidian检查包括边缘热区命中、悬停打开与移出关闭、双窗口独立导航、后台文章切换、失联root恢复、重复第3图放大与正文画廊联动、重载后每个面板各一份导航；原悬停模式与170 px导航宽度保持。结果见`hover-recovery-results.json`。
