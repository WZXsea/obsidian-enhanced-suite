# Citation Badges · 引用徽标

为 Obsidian 的标准脚注添加淡底上标徽标，并将直接相邻的脚注聚合为引用簇。支持实时预览与阅读模式，Markdown 保存形式保持为 `[^a][^b][^c]`。

## 显示规则

1. 同一脚注首次出现时获得一个显示编号，全文重复引用沿用该编号。
2. 直接相邻引用聚合成一个徽标；空格、标点、换行及正文保持独立边界。
3. 两项显示为 `1,2`，连续递增三项及以上显示为 `1–3`，混合编号显示为 `1–3,7`。
4. 引用顺序沿用源码顺序；同簇重复来源去重显示，所有原始引用位置保留。
5. 具名和数字脚注标识均支持。行内脚注参与原生编号序列，其正文保持 Obsidian 原生展示。
6. 实时预览的 callout 使用全文脚注编号，支持标题、正文、嵌套 callout 中的引用与相邻引用簇，并保留原生折叠、链接和任务勾选。

## 操作

1. 悬停显示来源列表，使用 210 毫秒的淡入与放大动效；浮窗以靠近引用符号的一侧为起点，上方浮窗向上展开，下方浮窗向下展开。原生正文高度变化时保持靠近符号的边缘固定。点击徽标固定列表，每条来源保留 Markdown 正文与原有链接。系统选择减少动态效果时直接显示。
2. 点击「定位」进入对应脚注定义，并将条目置于所属窗格中央。阅读模式中存在可见定义时直接定位；当前 Obsidian 将定义集中到脚注视图时，定位会切换到实时预览中的源码定义。
3. 通过命令「Citation Badges · 引用徽标：返回最近引用位置」返回原引用及原视图模式。
4. 两种视图的来源正文均使用 Obsidian 原生实时预览。点击普通正文直接放入光标并进入原位编辑；文本、格式及链接在同一区域呈现。停顿 150 毫秒后静默自动保存，引用簇中的来源分别保存。关闭或定位前会保存最后一次输入，异常时显示提示与处理入口。
5. Escape、再次点击已固定的徽标或点按弹层外部关闭来源列表；悬停列表移出后淡出。键盘可使用 Tab、Enter、Space 操作。
6. 设置页提供字号比例、淡底强度与圆角，并即时更新外观。
7. 编辑保留脚注标识与笔记其他内容。正文出现并行修改时，弹层保留草稿并提示核对；点击「重新载入」可载入当前正文。多段落、链接、列表及代码均按原生脚注格式保存。

光标或选区进入正文中的引用范围时，实时预览仍会展开完整引用簇源码，方便直接修改标识或顺序。

来源正文采用原生 Live Preview 的编辑行为：光标进入格式或链接区域时展开相应 Markdown 语法，其他区域继续显示排版效果。中文组合输入提交后保存，撤销使用各来源自身的编辑历史。

## 构建与安装

```sh
npm run build
npm test
# 已运行 Obsidian 时，执行原生 Markdown 解析回归：
CITATION_NATIVE_ORACLE=1 node tests/definition-edit.mjs
```

将 `main.js`、`manifest.json`、`styles.css` 复制到 vault 的 `.obsidian/plugins/citation-badges/`，随后启用插件。

## 实现与验证

全文模型区分源码标识、显示编号和每次引用的位置。实时预览采用 CodeMirror 行内 replacement widgets，阅读模式保留原生引用 id 并添加展示层。原生 Markdown 文件保持完整。

45 项纯模型与定向编辑测试覆盖原生编号、源码位置、引用簇、代码与注释、数学区域、多行定义、缩进、并行修改保护及长文场景。17 个原生解析样例验证脚注正文的多段落、列表、链接、代码及连续编辑。实际应用验收覆盖两种视图的正文直接编辑、原生格式操作与撤销、中文组合输入、关闭前保存、引用簇切换、居中定位、分栏滚动及返回原视图。

嵌入编辑器适配器独立管理正文缓冲区、焦点与生命周期；保存仍通过整篇笔记的定向脚注替换进行。适配器复用原生 ScrollableMarkdownEditor，构造器解析方法参考 [Kanban 的原生 MarkdownEditor](https://github.com/mgmeyers/obsidian-kanban/blob/main/src/components/Editor/MarkdownEditor.tsx) 和 [Fevol 的嵌入编辑器说明](https://fevol.github.io/obsidian-notes/notes/snippets/embeddable-markdown-renderer/)。

## Android 适配（0.3.3）

1. 点按正文中的引用徽标即可固定来源列表。触摸拖动继续滚动笔记，移动超过 10 px 或系统取消手势时会抑制来源列表的误触发。
2. 移动端来源正文使用 Obsidian 原生 Markdown 渲染。点按正文或「编辑正文」进入 Markdown 文本编辑，点击「预览正文」返回渲染结果。链接在预览中沿用原有打开方式。桌面端继续使用原位 Live Preview 编辑器。
3. 中文组合输入提交后静默保存。点按「关闭」、弹层外部或「定位」时，插件完成当前正文写回后执行操作。应用进入后台时也会触发保存。并行修改保护与「重新载入」入口沿用现有行为。
4. 来源列表宽度和高度跟随可视视口变化。软键盘弹出、页面平移、屏幕旋转时会重新定位，长正文在列表内滚动。移动端「关闭」「编辑正文」「定位」使用至少 44 px 高度的按钮。
5. 安卓安装目录为当前仓库的 `.obsidian/plugins/citation-badges/`。复制 `main.js`、`manifest.json` 和 `styles.css`，随后在 Obsidian 第三方插件设置中启用或重载。

自动回归包含 26 项引用模型测试、19 项定向写回测试和 7 项移动布局与手势测试。`npm run test:mobile-browser` 另外运行 4 组 Chromium 真实 DOM 回归，覆盖中文组合输入、两条来源反复切换预览与编辑、滑动和多指误触、关闭前写回及生命周期清理。该命令需要可用的 Playwright 与 Chromium，可通过 `CITATION_PLAYWRIGHT_PATH`、`CITATION_CHROME_PATH` 指定本地运行路径。移动布局覆盖竖屏、横屏、软键盘缩小视口、平移视口和极窄视口。Android 系统返回键、具体输入法的组合输入提交时序和系统后台行为以真机验收结果为准。
