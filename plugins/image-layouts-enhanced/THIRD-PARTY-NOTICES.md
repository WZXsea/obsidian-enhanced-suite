## Image Layouts baseline

Grid layouts and compatibility syntax are based on vertis/obsidian-image-layouts 0.18.0.
Source: https://github.com/vertis/obsidian-image-layouts/tree/0.18.0

Image Layouts Enhanced reimplements the renderer against Obsidian's public
Markdown and CodeMirror APIs, retaining the upstream grid geometry and image-layout
compatibility syntax. Filmstrip, focus thumbnails and the Image Toolkit bridge
are local extensions. Image parsing is adapted from weizixun's local Note Image
Sidebar project.
