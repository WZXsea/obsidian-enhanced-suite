# Table Column Resize 表格增强

基于当前安装的 lolieatapple / Table Column Resize 1.0.2，为阅读视图与实时预览添加列宽、整体宽度、字号与合并显示控制。插件 ID 保持 table-column-resize，当前库直接使用该插件。

## 功能

- 合并显示：先使用 Obsidian 原生选区选中待合并单元格，右键菜单直接选择“合并显示”；工具栏融合菜单也会读取当前选区并提供合并操作。阅读视图可通过“选择合并区域”指定起止格。区域内各格填写相同内容，支持横向、纵向和矩形合并。
- 合并显示保留原始 Markdown 格子与内容；tableMerges 在插件设置中记录范围，按文件、表头和源码表格序号区分。插入或移动整张表格后可重新选择合并区域。
- 实时预览点击合并格展开原表并定位原生单元格编辑器，可直接编辑或粘贴；点击表格外的正文或空白自动恢复融合；菜单“返回合并显示”同样可用。菜单“取消全部合并”恢复全部独立格子。
- Markdown 复制保留重复格子的原文；HTML 富文本复制保留 colspan/rowspan 合并结构。

- 整体宽度：工具栏双向箭头打开 1%–100% 滑块；右侧细握柄可直接拖动，居右时握柄位于左侧。
- 收窄默认居中，宽度菜单支持居左、居中、居右；tableWidths/tableAlignments 按表格身份保存并跨视图共享。
- 整体宽度变化保持列间比例；自定义宽度下拖动列宽重新分配相邻列，整体宽度保持固定。恢复默认宽度返回主题布局。

- Aa 左侧复制按钮：优先复制当前表格的 Markdown 原文，同时提供清理后的 HTML 富文本。成功后显示勾号约 1.6 秒。

- 表格右上方 Aa 按钮；主题配色、磨砂玻璃弹层。
- 菜单从按钮附近连贯缩放淡入（420 ms），14 px 滑块居中于 4 px 轨道，拖动时增加高光、光晕、轻微放大和实时进度。系统减少动态效果偏好使用静态显示。
- 10–40 px 滑条，即时预览；恢复主题默认字号。
- Escape、外部点击与滚动收起菜单。
- 字号独立存入 data.json 的 tableFontSizes，现有 columnWidths 保持自身格式。
- 使用原插件的 文件路径::表头指纹 定位，阅读视图和实时预览共享设置；同一文件内相同表头的表格也共享字号。
- 根据编辑器所在 MarkdownView 获取文件路径，支持多个编辑窗格。

## 构建

```sh
npm install --no-save esbuild
python3 build.py
node --check main.js
```

upstream 保存安装时的原始插件文件，font-control.js 和 font-control.css 保存字号功能，width-control.js 和 width-control.css 保存整体宽度及对齐功能；merge-identity.js、merge-render.js、merge-control.js 和 merge-control.css 保存合并显示功能，build.py 通过 esbuild 生成压缩后的 main.js/styles.css，同时保留 main.dev.js/styles.dev.css 供阅读与调试。构建文件安装到目标库 .obsidian/plugins/table-column-resize/。

上游插件更新会替换本地定制文件。此目录保留定制来源和构建脚本，便于在新版本基础上重新集成。

在当前 Obsidian 中核验实时预览、阅读视图、字体即时调整、重载恢复、默认恢复、Escape 关闭和其他表格字号隔离。字号操作期间列宽数据一致，既有列宽记录保留。UI 截图为 live-preview.png 和 reading-view.png。

实时预览修复：列操作区与字号按钮保持独立间距；表格重绘时重新绑定弹窗；拖动期间固定菜单位置，编辑器自动滚动保持弹窗显示。

## 运行与体积优化

- 字号菜单的 9 个全局事件由同一窗口共享，首次打开时注册；表格之间通过 WeakMap 与键索引定位。
- 字号观察器仅检查发生增删的相关表格；编辑器仅在文档或视口变化时安排扫描，每帧合并一次。
- 列宽初始化集中测量后写入，拖动更新每帧合并；松手前应用最后位置，再保存列宽。
- 实时预览复制依据 CodeMirror 原生文档行索引读取当前表格，阅读视图仅解析对应源码区段。
- 发布 JS 从 33,001 B 减至 20,170 B，CSS 从 10,438 B 减至 8,265 B，合计减少 34.5%。压缩包只包含发布文件与说明。

优化验证：Obsidian 临时 DOM 表格连续 20 次 pointermove 在松手时合并写入并保存最后列宽；字号 input/pointer 事件后弹窗保持打开；相同表头的第二张表格精确复制原文，HTML 清理保留。无关 DOM 插入样本的表格连接检查从 14 次降至 0 次。文件体积、事件数量与定向测试作为验收依据。

## 整体宽度验收

真实 Obsidian 阅读视图与实时预览：765 px 容器中 60% 宽度为 459 px；左、中、右对齐边距分别 0/306、153/153、306/0 px，工具栏边缘一致。列宽拖动后整体仍为 459 px；整体拖拽、居右左侧拖柄、字号、复制与默认恢复通过定向事件测试。51% 居中设置经重载在实时预览恢复为 390.15 px；验收临时笔记和设置已清理。

## 合并显示验收

在 Obsidian 临时笔记中通过选择起止格完成 2×2 合并；横向表头、纵向及矩形范围通过显示测试。原文读回保持一致，Markdown 精确复制原表，HTML 中合并内容显示一次。同表头的第二张表格具有独立合并标识。阅读与实时预览切换、重载恢复、整体宽度、列宽、编辑展开和返回融合经过定向交互核验。相邻列调节后整体宽度保持 535.5 px。相同区域内容一起改名后仍可显示合并；异文区域提示重新选择。取消合并恢复独立单元格。临时笔记和相关设置已清理。

## 原生选区与纵向居中修复

原生 selectCells 选中 2×2 格后，工具栏菜单自动读取范围并启用合并，隐藏重新选区按钮；原生 onContextMenu 注册合并菜单项并读取已选范围。合并前后编辑器原文一致。纵向合并单元格采用 vertical-align:middle，原生 .table-cell-wrapper 高度释放为 auto；实测格子高度 57.44 px、文字容器 28.72 px，两者中心差 0 px。临时验收笔记与设置已清理。

点击外部恢复验收：点击合并格展开后，表格内部与工具栏点击保持编辑；点击外部空白后恢复 rowspan=2、合并显示类，编辑虚线移除。仅在临时编辑期间注册外部点击监听，退出与销毁时清理。

## 表格引用兼容

实时预览原生表格会独立渲染单元格，脚注原先呈现为普通标记文字。citation-control.js 通过完整文档中的单元格位置匹配 Citation Badges 引用，增强含引用的只读单元格；沿用现有引用编号、来源弹窗与跳转，编辑中的单元格交给原生编辑器。

引用点击跳过合并格的展开逻辑，引用弹窗操作保持表格状态；同一脚注多次出现时，合并比较忽略隐藏原生编号的出现次数。HTML 复制保留可见引用编号，Markdown 继续复制原文。

定向验收：实时预览两处同脚注显示两个正确编号徽标，悬停及完整鼠标事件序列打开正确来源弹窗；纵向合并状态保持，操作前后编辑器原文一致。阅读视图重复脚注合并通过；返回实时预览后脚注与 rowspan=2 恢复。无新增全局观察器与监听，临时笔记和设置已清理。

## 动态选区与内容判定修复

实时预览以原生单元格 text 判断内容，避免同时读取隐藏只读内容与正在编辑的文本；同样内容不会因 DOM 重复显示而判为异文。DOM 行列变化后，读取选区和应用合并前同步实际格子引用及坐标。

定向验收：两个“毒素介导疾病”单元格，其中一格 DOM 文本因原生编辑器显示两遍，原生选区仍正确启用合并并得到 colspan=2；动态增加 DOM 行后，缓存格子数从 2 更新为 3，新增同行两格合并成功。临时验收笔记及设置已清理。

## 首次粘贴修复

合并表格首次点击展开时，同时使用原生 EditorSelection 定位目标单元格。input-control.js 在每个源编辑器共享一个 editTableCell 接入点，将原生单元格剪贴板事件的 editor 参数交给当前单元格适配器，保留 Linter 等插件的粘贴清理。切换单元格和卸载时恢复原接口。编辑器首次表格扫描合并到动画帧；按实际控制器映射识别表格，恢复缓存 DOM 上失效的工具栏与手柄绑定。

验收：空单元格首贴“空格首贴”后，单元格与 Markdown 对应位置均包含一次文字，剪贴板事件内容保持原值；非空单元格首次粘贴保留原文字且新增文本出现一次。临时笔记与验收设置已清理。插件热重载后调用各 MarkdownView editMode.updateOptions 更新已打开编辑器的扩展，保持源编辑器使用当前实现。

## Android 适配（1.0.3）

1. 阅读视图和实时预览的复制、字号、宽度及合并入口采用 44 px 触控按钮，打开菜单后可点按滑块、对齐和恢复按钮。
2. 列边缘采用 20 px 的触控命中区，表格整体宽度握柄采用 28×44 px 命中区。手指从握柄开始水平拖动，松手后保存。表格其他区域沿用 Obsidian 的滚动操作。
3. 合并菜单的“选择合并区域”支持依次点按起点与终点。触摸动作在抬指后确认，滑动和系统取消手势交还滚动处理。包含相同内容的矩形选区可合并显示。
4. 字号、宽度、合并弹层按 Android 可见视口定位并限制高度，适应软键盘、横竖屏和分屏变化。内容较长时可在弹层内滚动。
5. Android 复制优先使用浏览器剪贴板，旧版 WebView 使用同步文本复制回退。桌面环境继续支持 Markdown 与 HTML 双格式。插件设置沿用现有数据格式。

安装时将本目录的 `main.js`、`manifest.json`、`styles.css` 放入 Android 库的 `.obsidian/plugins/table-column-resize/`，在 Obsidian 第三方插件中启用或重新加载。


8 项回归覆盖主指针隔离、取消/失焦/失去捕获与卸载清理、末帧保存、软键盘可见视口定位、点按与滚动区分、移动端剪贴板及其回退。此处结果反映代码与模拟事件验证，Android 真机上的 WebView、主题和输入法行为以设备验收为准。

## 一键紧凑排版（1.0.4）

1. 点击表格右上方的向内收拢图标（提示“一键紧凑排版”），同时调整各列和整体宽度。编号、状态等短文本列按内容收窄，长文本列分配较多宽度并自动换行。
2. 全表内容较少时，整体宽度按内容收窄。全表内容较多时，整体宽度受正文容器限制，长列共同分配剩余空间。
3. 测量采用当前字号、单元格内边距和富文本内容，覆盖换行、图片、引用徽标以及正在编辑的单元格。测量树即时清理，原始 Markdown 保持逐字一致。
4. 合并表格在完整原格上计算宽度，完成后恢复合并显示。阅读视图与实时预览共享保存的整体百分比及各列比例，重载后恢复布局。
5. 紧凑后继续拖动列边缘可调整相邻两列，整体宽度保持固定；双向箭头菜单继续提供整体宽度与对齐控制。“恢复默认宽度”清除紧凑比例并恢复主题整体宽度及已保存的手动列宽。
6. 仅在点击时按当前内容计算。内容或字号变化后，再次点击可更新布局。同文件中同表头的表格沿用现有宽度共享规则。

数据新增 `tableColumnRatios`，保存各列相对宽度。`columnWidths` 继续保存手动列宽，自动排版保留这些历史值；原有字号、合并与对齐字段沿用当前格式。

桌面实测：624 px 表格的两列短文本从各 208 px 收窄至约 56 px，说明列获得约 512 px；两列短表整体从 624 px 收窄至 78 px。重载、跨视图恢复、合并保留、整体宽度缩放、相邻列微调及原文一致性通过定向核验。

回归：`node --test tests/*.test.cjs`，18 项通过。验证记录与截图位于工作区 `qa/table-auto-fit-20261026/`。

360×800 手机模拟通过：正文可用宽度 312 px，长表保持 312 px，短表收至 78 px，紧凑按钮为 44×44 px。触摸调节相邻两列后，第三列宽度保持约 200 px。模拟结束已恢复桌面模式与原活动笔记。
