## Image Layouts Enhanced · 图片画廊

## 图片导航联动修正（0.1.7）

图片导航按图片的源码位置切换图库内容，重复图片沿用各自索引。定位保留阅读模式，图库中的目标图片会显示于主图区域。


## Android 适配（0.1.6）

1. 点按画廊图片或放大按钮打开查看器。Image Toolkit 1.4.16 提供移动端原生 Modal 桥接。独立查看器同样支持单指平移、双指缩放、旋转、上一张、下一张和关闭。
2. 在正文普通图片或画廊图片上保持按压约 450 毫秒，可显示“布局”和“设置”入口。移动手指、滚动、第二根手指触碰或系统取消触摸均会取消待触发的长按。普通短按保留图片查看操作。
3. 轮播和聚焦视图保留横向滑动切图与纵向正文滚动。触屏按钮采用至少 44 px 的点击区域。浮动编辑面板根据软键盘后的可视区域重新定位。
4. 自动化验证覆盖手势缩放与平移、取消与清理、长按和滚动区分、画廊精确索引、软键盘可视区域与 Android 模块加载。真机触摸延迟、WebView 渲染及主题组合由设备验收确认。

独立的 Obsidian 图片布局插件，以 [Image Layouts 0.18.0](https://github.com/vertis/obsidian-image-layouts/tree/0.18.0) 的拼图、瀑布流和轮播为基准，增加横向图片带与主图联动侧边方格。正文布局由本插件渲染，图片放大优先联动 Image Toolkit。

新图片组使用成对隐藏注释包围普通 Markdown 图片，正文仅记录布局与短标识。显示细节保存在插件 `data.json` 中。笔记仍保存原来的图片引用、原文图注与正文；插件关闭后，图片按照 Obsidian 原生方式显示。源码模式显示可编辑文本；阅读视图显示画廊；Live Preview 在光标离开图片组时显示画廊，光标进入组内时显示可编辑引用。

## 使用
1. 将鼠标移到正文图片上，右上角出现“布局”按钮。点击后在图片旁的小弹出框中选择相邻图片：左击确定连续范围，按住右键划过缩略图可扩展选择，然后点击“布局”。候选版式按实际选图数量提供。
2. 已有画廊的图片旁显示“布局”和“设置”：前者切换版式，后者打开紧凑设置浮层，调整高度、间距、圆角、适配方式、图注和缩略图；说明显示、对齐、宽度与自定义网格位于“高级设置”。
3. 阅读视图和 Live Preview 均提供图片旁入口；光标进入图片组、显示原生图片引用时，仍可使用这些按钮。工具条随鼠标离开、图片所在页面滚动或 Escape 收起；旁侧缩略区的滚动保留主图旁的入口。
4. 分组按正文顺序连续选择，组内图片、图注和正文原样保留；相邻章节与已有图片组构成选择边界。
5. 组内工具栏使用布局、图片适配、设置、编辑引用、恢复普通图片五个图标；悬停可查看操作名称与当前状态。点击编辑引用图标，在图片旁编辑这组原生图片链接与图注，保留当前阅读视图或 Live Preview。支持中文输入、粘贴、换行以及 ⌘／Ctrl + Enter 保存；取消放弃本次修改，点击外部自动收起时保留同源草稿。正文其他位置的新增编辑一并保留；同一组发生冲突时，在浮层内提示并保留输入。选中正文引用后，也可通过命令面板创建画廊。
6. 主图组合中的小图点击后切换到大图区域，原主图回到对应小图位置。主图点击或右上角“放大”入口联动 Image Toolkit。
7. 对旧图片组执行“精简当前笔记的图片组标记”，将详细参数迁移到插件配置，正文保留布局与标识。

| 命令 | 用途 |
| --- | --- |
| 将选中图片组成画廊 | 将选中的图片段落组成新组并选择布局 |
| 当前图片组：选择布局 | 在光标所在图片组切换版式 |
| 当前图片组：恢复普通图片 | 将光标所在图片组还原为普通图片 |
| 精简当前笔记的图片组标记 | 迁移详细参数到 `data.json`，精简开头标记，并显示配置与标记数量 |
| 插入图片组模板 | 插入可替换图片路径的横向图库模板 |

图片源采用 Vault 附件、HTTP(S) URL 或 `data:image`，可使用 Wiki 图片、Markdown 图片、引用式图片与 HTML `img`。隐藏注释组中的引用式图片可使用组外的定义。同一图片的多次引用保留各自顺序与对应说明。独立图注段落和正文保留在组内，显示在图库下方。

操作浮层采用圆角玻璃表面、轻微浮起与淡入淡出动效，适配系统的“减少动态效果”。高度、间距和圆角滑块显示当前数值，设置保存成功后刷新对应画廊。

横向浏览布局支持方向按钮、左右方向键及 Home／End；横向图片带可通过触控板或横向滚动条浏览。方向键在画廊获得键盘焦点时切图。

## 布局
| 布局值 | 显示方式 |
| --- | --- |
| `a` / `b` / `c` | 双图等宽／左大右小／左小右大 |
| `d` / `e` | 左侧／右侧主图，旁边两张小图 |
| `f` / `g` | 左侧／右侧主图，旁边三张小图 |
| `stage-left` / `stage-right` | 按实际图片数量生成左侧／右侧主图与全部小图组合 |
| `h` / `i` / `single` | 三图等宽／四图等宽／单图 |
| `masonry-2` … `masonry-6` | 两至六列瀑布流 |
| `carousel` | 单主图与底部横向缩略图 |
| `filmstrip` | 等高图片横向排列，宽度按图片比例调整 |
| `focus` | 单主图与右侧两列方格缩略图；窄面板改为底部缩略图 |
| `custom` | 使用字母网格定义静态拼图 |

固定拼图按精确数量提供：双图版式用于两张，主图与两图用于三张，主图与三图用于四张。五张及以上提供按数量生成的主图组合和完整网格；主图组合在侧边网格中完整放置其余图片。既有笔记的图片数变化后，布局自动调整以完整呈现当前数量。横向图片带、轮播和侧边方格作为浏览版式供选择。

## 图片组与配置
开头和结尾标记分别占一行，中间保留图片引用和正文。自动生成的开头注释仅保存 `layout` 与 10 位短标识；既有唯一标识继续保留。高度、图注、图片适配和自定义网格等细节通过图片旁的“设置”浮层保存到插件配置：

```markdown
<!-- image-layouts: {"id":"9a37c42d10","layout":"focus"} -->

![[影像1.png|正位]]

![侧位](影像2.png)

这里保留图注和相关说明。

<!-- /image-layouts -->
```

| 显示配置 | 含义 |
| --- | --- |
| `layout` | 上表中的布局值，默认 `g` |
| `fit` | `contain` 完整等比显示；`cover` 裁切填满区域；`natural` 保持图片自身比例并限制最大宽高 |
| `height` | 主图或等高画廊区域的像素高度，默认 `320`；显示配置接受 `120–1200` |
| `gap` / `radius` | 图片间距与圆角，默认各 `8` px |
| `caption` / `descriptions` | 整组图注／逐图说明；逐图说明也可写入图片 alt 或 Wiki 图片的竖线文字 |
| `thumbnails` | 轮播和主图布局使用缩略图；设为 `false` 时使用序号按钮 |
| `overlay` | 拼图和横向图片带的逐图说明采用 `never` 图片下方、`hover` 悬停叠加或 `always` 持续叠加；主图与瀑布流的说明位于图片下方 |
| `align` / `width` | 左、居中、右或满宽排列，以及安全的 CSS 尺寸，如 `"50%"`、`"480px"` |
| `fromFolder` | 追加指定 Vault 文件夹中直接包含的图片 |
| `sortBy` / `reverse` / `limit` | 文件夹图片按 `name` 或 `mtime` 排序、倒序和数量上限；`limit: 0` 表示全部 |

科研图与教材图宜使用 `contain`，完整保留坐标轴、比例尺和图内文字；照片拼图可使用 `cover`。瀑布流按列宽与图片原始比例确定高度。设置页的默认高度范围为 `180–640` px，组内设置浮层提供 `120–1200` px，新图片组保存独立显示参数。

原生 `![[图.png|300]]`、`![[图.png|300x200]]` 和 `![[图.png|说明|300]]` 写法完整保留在笔记中，数字尺寸与文字说明分开处理。图库内部尺寸由布局及 `height`／`width` 控制；恢复普通图片或关闭插件后，原有尺寸继续由 Obsidian 原生渲染。

自定义布局选择 `custom`，随后在“设置”中输入字母网格，例如：

```text
A A B
A A C
```

相同字母合并成一个矩形区域，字母按首次出现顺序对应图片，`.` 表示空位。每行格数保持一致，每个字母区域组成完整矩形。网格内容保存到插件配置。

配置文件位于 `.obsidian/plugins/image-layouts-enhanced/data.json`，按笔记路径与图片组标识独立保存显示细节。文件或文件夹在 Vault 内重命名时，配置随路径迁移；恢复普通图片后保留配置，便于撤销还原。跨设备同步该文件与相同路径的笔记可保留完整显示设置；单独复制 Markdown 到另一笔记或 Vault 时，按正文中的布局与默认参数显示。

## Image Toolkit 联动与旧笔记
完整联动使用本次开发提供的 Image Toolkit **1.4.17** 定制版，其 `imageLayoutBridgeVersion: 1` 适配桥将当前组的图片顺序、重复引用和选中位置传入 Toolkit。启用两插件后，主图点击可沿用 Toolkit 的放大、拖动、旋转及底部画廊。适配桥不可用或图库打开失败时，本插件使用独立图片查看器，提供缩放、拖动、旋转及前后切换。联动按适配桥能力检测，社区原版 Toolkit 可继续用于普通图片查看。

兼容原 `image-layout`、`image-layout-a` … `image-layout-i`、`image-layout-single`、`image-layout-masonry-2` … `image-layout-masonry-6` 代码块，以及 `image-layout-left`／`center`／`right` 单图快捷块。现代 `image-layout` 块中的 YAML `layout` 可选择字母拼图、`single`、`masonry-N`、`carousel`、`custom`；`legacy-layout-a` 等旧名称也可识别。

兼容原代码块时，以本插件作为其渲染入口。阅读既有代码块保留原格式；通过画廊工具栏保存布局、显示方式或组内设置时，详细配置保存到 `data.json`，该块转换为简短隐藏注释图片组；“恢复普通图片”保留图片正文。可确定该块源码范围的笔记视图支持转换保存，嵌入和导出等上下文提供布局展示。

`carouselShowThumbnails`、`carouselHeight`、`permanentOverlay` 等旧选项可映射到对应显示参数。高度使用像素数值或 `px` 字符串。旧隐藏注释中的显式参数继续优先读取；保存设置或执行精简命令时迁移到外部配置。

## 构建与安装
当前开发目录复用上级工作区的 `node_modules`：

```sh
npm run build
npm test
```

将 `main.js`、`manifest.json`、`styles.css` 放入目标 Vault 的 `.obsidian/plugins/image-layouts-enhanced/`，在“第三方插件”中启用“Image Layouts Enhanced · 图片画廊”。分发时同时保留本说明与第三方许可声明。
