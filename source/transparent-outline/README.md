# Transparent Outline

透明右侧文章大纲，默认悬停显示，另提供常开与关闭模式。面板贴附每个 Markdown 页面，正文宽度保持原值。标题按 H1–H6 缩进，点击跳转，带子标题的条目可折叠。

## 0.3.4 手机和平板收起后的正文滚动

移动目录的触摸区域随显式打开状态切换。收起后，原面板区域直接命中正文，右缘“目录”按钮继续提供入口。桌面悬停与键盘焦点展开规则限定在桌面面板，移动端的焦点、触屏悬停和层级滑条状态由移动展开规则统一处理。

执行 `npm run test:mobile-browser` 可复核手机与平板的收起命中、残留悬停和焦点、正文触摸滚动，以及目录入口与列表滚动。

## 使用

将 `main.js`、`manifest.json`、`styles.css` 放入 vault 的 `.obsidian/plugins/transparent-outline/` 并启用。通过设置或命令切换悬停、常开、关闭；面板上方的小圆按钮切换悬停/常开。右侧透明触发条支持鼠标与键盘，点击切换为常开；Escape 收起悬停展开状态。显示模式、宽度和文字透明度随插件设置保存，折叠状态保留在当前打开的页面内；标题结构更新后重置折叠。关闭模式可通过命令面板的“Transparent Outline: 悬停显示大纲”恢复。

## 数据与兼容

标题来自 Obsidian metadataCache，包括 ATX 与 Setext 标题，编辑后的标题在缓存更新后刷新。当前章节自动滚入大纲可见区域。阅读模式高亮跟随章节滚动，编辑模式高亮通过版本保护的 CM6 几何适配跟随滚动，适配不可用时使用光标所在章节。每个页面拥有自己的 controller，点击定位在所属页面完成。阅读模式通过 Obsidian 行位置定位，高亮通过带版本保护的渲染段落行号映射；源码与实时预览通过 Editor API 定位。阅读中的嵌入文章标题由段落行号区分。窗口布局与模式变化会重新扫描 Markdown leaves。

## 构建与验收

执行 `npm run build`，复用父目录的 TypeScript 与 esbuild。建议在阅读、实时预览、源码及分栏中验证悬停展开、常开、关闭、重复标题定位、折叠、长标题、无标题笔记、切换文件与卸载清理。

调试入口：`app.plugins.getPlugin('transparent-outline').controllers` 为 `Map<MarkdownView, OutlineController>`；controller 公开 `root`、`list`、`headings`、`activeIndex`、`collapsed`、`jump(index)`、`refresh()`、`updateActive()`。plugin 公开 `setMode('hover'|'pinned'|'off')` 与 `refreshAll()`。卸载清理 observers、DOM listeners、延迟计时器及 animation frames。

## 0.2.0 背景效果

背景效果提供“窄窗口自动磨玻璃”“纯透明”“始终磨玻璃”“半透明底色”。默认按当前文章栏宽度判断：低于900px启用磨玻璃，宽栏使用纯透明；分栏和窗口调整即时更新。主题颜色跟随Obsidian浅色/深色主题，深色默认82%遮蔽，浅色默认88%遮蔽，模糊半径16px。可以调整自动启用宽度、遮蔽强度及模糊半径。

背景仅在大纲展开时显示，左侧采用柔和渐隐，保留零边框外观。收起和关闭恢复文章展示。背景效果支持悬停与常开模式。

## 0.3.0 展开层级调节条

大纲顶部新增六档调节条，支持拖动圆形滑块、点击数字节点及键盘方向键。档位表示目录树的展开深度：第1档显示文章顶层，第2档展开到子章节，第6档展开全部层级。标题从H2/H3起始或跳过某个标题等级时，按实际父子关系计算目录层级。

细轨道、圆形节点和主题强调色进度与透明/磨玻璃背景协调，圆形滑块带悬停和键盘焦点反馈。设置在当前插件各页面间同步并持久保存。单个章节箭头可单独展开或折叠，重新调整滑条后统一恢复到所选层级。背景与调节条随悬停状态共同淡入淡出。

## 0.3.1 展开与收起动画

层级滑条及单章节箭头触发展开时，条目以280ms的高度展开与轻微淡入进入；收起时以220ms收缩与淡出退出。箭头以240ms旋转，采用柔和减速曲线。快速反向调整从条目当前高度和透明度接续，结束后恢复自然高度；隐藏条目在过渡期间设为inert，保护键盘和鼠标交互。

初次加载、后台页面及收起的大纲直接更新最终状态。系统“减少动态效果”启用时直接切换。页面重建、切换及插件卸载清理进行中的动画。

## 0.3.2 页面滚动条避让与夜间可读性

大纲为页面滚动条预留至少 15px，并额外留出 14px 间隔。编辑、阅读及窄栏采用相同避让规则，层级调节条和展开动画保持原有交互。

夜间的自动背景模式在各栏宽度下启用磨玻璃，默认遮蔽强度 92%、模糊半径 24px、目录文字透明度至少 92%。深色模式在基础遮蔽值上增加 10 个百分点（最高 98%），模糊半径增加 8px；浅色模式保留原有宽度策略。纯透明选项保留。

## 手机与平板快捷入口

移动端每个 Markdown 页面下方增加带文字的“搜索 / 图片 / 目录”快捷条，按钮提供至少 44px 触摸区域。搜索与图片入口随相关插件的加载状态显示，目录入口始终可用。快捷条位于底部原生功能栏上方，并为安全区域留出空间。软键盘占用可视区域或弹出 Modal 时，快捷条暂时收起。

1. 点按底部“目录”、文章右缘“目录”按钮，或标题栏“目录”动作，可展开当前文章目录。点按目录面板“关闭”或正文区域可收起。
2. “悬停”模式在手机和平板上采用点按展开，目录列表滚动和层级调节期间保持展开。桌面鼠标悬停行为继续保留。
3. 点按标题定位到所属页面。编辑模式通过 Editor API 更新位置，并保持编辑区失焦，便于只导航时控制软键盘。
4. 页面更多菜单提供“打开文章目录”和“打开右侧完整目录”。命令“打开或收起当前文章目录”亦可触发。
5. 显示方式为“关闭”时，底部和标题栏入口继续可用。主动点按后恢复悬停设置并展开当前目录。移动端默认展开至第 2 层，并使用独立的 `mobileDepth` 设置。桌面 `depth` 偏好继续保留，两端均可在面板顶部选择 1–6 层。

移动调试入口为 `plugin.toggleForView(view)`、`plugin.openForView(view)`、`plugin.openNativeOutline()`。controller 增加 `isMobileOpen` 与 `setMobileOpen(boolean)`。快捷条选择器为 `.to-mobile-quickbar`，三个按钮分别为 `.to-mobile-quick-search`、`.to-mobile-quick-images`、`.to-mobile-quick-outline`。右缘和关闭按钮分别为 `.to-outline-edge`、`.to-outline-close`。

定向回归执行 `node --test tests/mobile-actions.mjs`，覆盖关联插件可见性、移动搜索命令回退、图片/目录路由和键盘高度判断。

“打开右侧完整目录”优先打开已启用的 Quiet Outline，其他环境使用 Obsidian 核心大纲。底部快捷条会测量原生移动功能栏位置并动态避让。
